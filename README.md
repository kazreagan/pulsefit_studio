# pulsefit_studio

## Overview
PulseFit Studio is a sleek and responsive fitness studio website designed to engage users and provide essential information about the studio's offerings. The site features:

- A visually appealing hero section.
- Navigation buttons linking to various workout programs and pages.
- A fixed footer with social media icons.

This project demonstrates the use of HTML, CSS, Bootstrap Icons, and custom styles for a modern web interface.

---

## Features
### 1. Hero Section
- Displays the studio name, tagline, and a background image to grab the user's attention immediately.

### 2. Navigation
- Buttons linking to different pages:
  - 30-Day Beginner Routine
  - Kettlebell Training Program
  - Bodyweight Training
  - Personal Training
  - About PulseFit Coaching
  - Contact Us

### 3. Footer
- Fixed at the bottom of the page.
- Includes social media icons for GitHub, Twitter, and Instagram.
- Icons are interactive, scaling up on hover with a color transition effect.

---

## Technologies Used
1. **HTML**: For the structure of the website.
2. **CSS**: For custom styling.
3. **Bootstrap Icons**: For social media icons.
4. **Font Awesome**: Alternative for icons.

## How to Run the Project
1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-username/pulsefit_studio.git
   ```

2. **Navigate to the Project Directory:**
   ```bash
   cd pulsefit-studio
   ```

3. **Open the `index.html` File in a Browser:**
   - Double-click on the `index.html` file.
   - Alternatively, use a live server extension in a code editor (e.g., VSCode).
